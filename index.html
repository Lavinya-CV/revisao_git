Atalhos do VS Code

Consulte os principais atalhos para editar, navegar e trabalhar com mais produtividade no Visual Studio Code.

Edição

  • Desfazer Ctrl + Z
  • Refazer Ctrl + Y
  • Copiar linha Shift + Alt + ↓
  • Mover linha Alt + ↑ / ↓
  • Comentar linha Ctrl + /
  • Formatar documento Shift + Alt + F

Navegação

  • Paleta de comandos Ctrl + Shift + P
  • Ir para arquivo Ctrl + P
  • Ir para linha Ctrl + G
  • Ir para símbolo Ctrl + Shift + O
  • Alternar editor Ctrl + 1 / 2 / 3
  • Fechar editor Ctrl + W

Pesquisa e seleção

  • Localizar Ctrl + F
  • Substituir Ctrl + H
  • Localizar no projeto Ctrl + Shift + F
  • Selecionar ocorrência Ctrl + D
  • Selecionar todas Ctrl + Shift + L
  • Expandir seleção Shift + Alt + →

Visualização

  • Terminal integrado Ctrl + `
  • Explorador Ctrl + Shift + E
  • Controle de código-fonte Ctrl + Shift + G
  • Extensões Ctrl + Shift + X
  • Dividir editor Ctrl + \
  • Zen Mode Ctrl + K, Z

Depuração

  • Iniciar depuração F5
  • Parar depuração Shift + F5
  • Executar sem depurar Ctrl + F5
  • Breakpoint F9
  • Continuar F5
  • Passo a passo F10

Arquivos

  • Salvar Ctrl + S
  • Salvar tudo Ctrl + K, S
  • Novo arquivo Ctrl + N
  • Abrir pasta Ctrl + K, Ctrl + O
  • Reabrir editor fechado Ctrl + Shift + T
  • Renomear símbolo F2
Os atalhos podem variar conforme o sistema operacional. Esta lista usa o padrão Windows/Linux.
